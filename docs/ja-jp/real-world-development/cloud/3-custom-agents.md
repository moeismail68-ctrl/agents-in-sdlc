カスタムエージェントを使うと、特定の役割、指示、ツールを持つ専門エージェントを定義できます。

## エージェントを確認する

リポジトリで利用可能なカスタムエージェントを確認し、次を確認します。

- エージェントの目的
- 使用する指示
- 利用可能なツール
- エージェントに求められる成果物

## エージェントを使用する

Issue またはセッションでレビュー担当エージェントを選択し、要件、テスト、実装の一致を確認させます。
