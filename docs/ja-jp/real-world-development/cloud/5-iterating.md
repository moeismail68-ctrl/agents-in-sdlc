エージェントが変更を作成したら、コードレビューとテストのプロセスを使用して確認します。

## PR を確認する

1. エージェントが作成した PR を開きます。
2. 差分と変更されたファイルを確認します。
3. Issue の要件と照合します。
4. チェックとテストの結果を確認します。

## フィードバックを反映する

修正が必要な場合は、レビューコメントまたは追加のセッション指示で具体的なフィードバックを与えます。エージェントが変更を反映したら、再度テストとレビューを実行します。

## 完了と次のステップ

すべての要件を満たし、チェックが成功し、レビューが完了したら PR をマージします。
