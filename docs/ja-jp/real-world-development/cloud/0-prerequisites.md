この演習では、GitHub Copilot cloud agent のワークショップを開始するための準備を行います。

## 必要なもの

- Copilot の有効なプラン
- GitHub 上でリポジトリを作成できる権限
- Tailspin Toys テンプレートを使用できる権限
- Copilot cloud agent がアカウントまたは組織で有効になっていること

## リポジトリを作成する

1. Tailspin Toys テンプレートリポジトリを使用して、新しいリポジトリを作成します。
2. リポジトリ名を設定し、プライベートまたはパブリックを選択します。
3. GitHub 上でリポジトリを開きます。

## 次のステップ

リポジトリを準備できたら、カスタム指示の演習へ進みます。
