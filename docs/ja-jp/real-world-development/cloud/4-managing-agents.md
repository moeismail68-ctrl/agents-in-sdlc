agents ダッシュボードを使うと、複数の cloud agent セッションを監視し、進行状況を確認し、作業を誘導できます。

## セッションを監視する

1. agents ダッシュボードを開きます。
2. 対象のセッションを選択します。
3. エージェントの活動と変更を確認します。
4. PR が作成されたことを確認します。

## セッションを誘導する

エージェントの方向が要件と合っていない場合は、追加の指示を送ります。指示は具体的にし、Issue の要件、テスト、ドキュメント、制約を参照してください。
