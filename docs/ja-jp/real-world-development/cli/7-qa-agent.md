品質確認は、実装から切り離すと漏れを見つけやすくなります。このレッスンでは、要件、カバレッジ、検証証拠をレビューする QA エージェントを作成します。

このレッスンでは、次の操作を行います。

- カスタムエージェントの役割とツールを定義します。
- エージェントをリポジトリへ追加します。
- QA エージェントを選択してフィルター機能をレビューさせます。

## カスタムエージェントを作成する

カスタムエージェントは、特定の作業に特化した指示とツールを持つ再利用可能なプロファイルです。

1. リポジトリの `.github/agents` フォルダーへ移動します。
2. QA エージェント用の Markdown ファイルを作成します。
3. エージェントに、要件との一致、テストカバレッジ、ブラウザー検証の証拠を確認する役割を与えます。
4. 変更をしないレビュー専用の動作を指定します。

エージェントの指示には、次を含めます。

- Issue の要件を列挙する。
- 実装とテストの対応を確認する。
- 期待される動作と欠落しているテストを区別する。
- Playwright の結果やスクリーンショットを確認する。
- 問題を重大度順にまとめる。

## QA エージェントを実行する

1. Copilot CLI のエージェント選択 UI を開きます。
2. 作成した QA エージェントを選択します。
3. フィルター機能、Issue、計画、テスト、ブラウザー検証を提示します。
4. エージェントに、結果と検証が完了した証拠を報告させます。
5. 報告された問題があれば修正し、再度レビューします。

## 要約と次のステップ

QA カスタムエージェントを作成し、要件、テストカバレッジ、ブラウザー検証を確認する役割を与えました。

次は、フィルター PR を作成し、エージェントによるレビューとマージを行います。
