このワークショップでは、GitHub Copilot CLI を使って Tailspin Toys に星評価とフィルター機能を追加し、変更をレビューしてマージしました。

学習した主な内容は次です。

- Copilot 会話と Git ブランチを使った作業。
- Plan モードと Autopilot モードを使った機能の設計と実装。
- Interactive モードでの変更レビュー。
- リポジトリ指示とスキルによるプロジェクト規約の適用。
- Playwright MCP を使ったブラウザー検証。
- QA カスタムエージェントを使った要件とテストカバレッジの確認。
- PR の作成とマージ。
- スラッシュコマンドによるコンテキスト、モデル、共有、クラウド委任の管理。

## 次のステップ

学んだカスタマイズをほかのリポジトリへ適用し、チームのドキュメント、テスト、レビュー基準に合わせて調整してください。変更を小さく保ち、マージ前に常に差分、チェック、ブラウザー動作を確認してください。
