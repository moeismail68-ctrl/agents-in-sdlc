VS Code の Agent mode を使うと、Copilot がリポジトリを調査し、計画を立て、コードを編集し、テストを実行できます。

## 検査対象の Issue を選ぶ

フィルター機能を説明している GitHub Issue を開き、要件を確認します。

## Agent mode を使う

1. Copilot Chat を開きます。
2. Agent mode を選択します。
3. Issue の要件と実装すべき動作を入力します。
4. Copilot の提案とファイル変更を確認します。
5. 必要に応じて、計画や実装を修正するよう依頼します。

## 変更を確認する

Source Control または diff ビューで変更を確認します。Issue の要件、テスト、アクセシビリティを満たしていることを確認し、失敗があれば修正します。
