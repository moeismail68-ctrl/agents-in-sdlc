このワークショップでは、VS Code と GitHub Copilot を使って Tailspin Toys のフィルター機能を実装します。

## 必要なもの

- GitHub アカウント
- 有効な Copilot プラン
- Visual Studio Code
- GitHub Copilot 拡張機能
- Codespace またはローカル開発環境

## リポジトリを準備する

1. Tailspin Toys テンプレートからリポジトリを作成します。
2. VS Code または Codespace でリポジトリを開きます。
3. Copilot 拡張機能へサインインします。
4. ターミナルで依存関係のセットアップと起動方法を確認します。

準備ができたら、カスタム指示の演習へ進みます。
