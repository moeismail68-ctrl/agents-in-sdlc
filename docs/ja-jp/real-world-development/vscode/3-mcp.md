Model Context Protocol (MCP) を使うと、Copilot はブラウザーや外部サービスなどのツールへアクセスできます。

## MCP サーバーを設定する

必要な MCP サーバーの設定を確認し、VS Code の MCP サポートを使って有効化します。サーバーを追加する前に、公開者、ソース、権限、セキュリティ上の影響を確認してください。

## ブラウザーで検証する

1. アプリを起動します。
2. Copilot に Playwright MCP を使ってフィルター機能を確認するよう依頼します。
3. カテゴリ、発行元、組み合わせ、リセット、結果が空の場合の動作を確認します。
4. 発見した問題を修正し、再検証します。

> [!CAUTION]
> MCP サーバーはプロジェクトの依存関係と同様に扱ってください。ソースと権限を確認してから使用してください。
