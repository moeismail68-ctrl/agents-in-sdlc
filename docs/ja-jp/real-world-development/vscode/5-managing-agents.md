エージェントによる作業は、セッションを監視し、結果を確認し、必要に応じてフィードバックを与えることで管理します。

## セッションを確認する

Copilot Chat または agents ダッシュボードで進行中のセッションを確認します。エージェントが実行したツール、変更、テスト、エラーを確認します。

## PR をレビューする

1. エージェントが作成した PR を開きます。
2. Issue の要件と差分を照合します。
3. テストと CI の結果を確認します。
4. レビューコメントや追加指示でフィードバックを与えます。
5. 修正後に再検証し、問題がなければマージします。
