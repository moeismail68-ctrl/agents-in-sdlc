このワークショップでは、Copilot app を使ってスペースクイズを作成し、ブラウザーで動作確認しました。最後のステップは、クイズを GitHub Pages にデプロイして、ほかの人がアクセスできるようにすることです。

このレッスンでは、次の操作を行います。

- リポジトリの GitHub Pages 設定を確認または構成します。
- デプロイを開始します。
- 公開されたサイトが正しく動作することを確認します。

## GitHub Pages を有効にする

1. リポジトリの **Settings** を開きます。
2. 左側のナビゲーションで **Pages** を選択します。
3. **Source** で **GitHub Actions** を選択します。
4. デプロイワークフローを起動します。

> [!NOTE]
> リポジトリがプライベートの場合、アクセス権を持つユーザーだけが公開されたサイトを閲覧できる場合があります。

## デプロイを確認する

1. リポジトリの **Actions** タブを開きます。
2. 完了したデプロイワークフローを選択します。
3. デプロイジョブと公開 URL を確認します。
4. 公開された URL をブラウザーで開きます。

## 次のステップ

GitHub Pages にクイズを公開できました。リポジトリの変更履歴と公開されたサイトを確認し、必要に応じてクイズを更新してください。
