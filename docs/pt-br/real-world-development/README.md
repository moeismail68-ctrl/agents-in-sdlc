**GitHub Copilot** pode ajudá-lo a criar, revisar e entregar alterações em um projeto realista. Estes workshops usam o mesmo aplicativo Tailspin Toys em diferentes ambientes para que você possa praticar fluxos de trabalho baseados em agentes.

## Escolha seu ambiente

| Ambiente | Cenário |
|----------|---------|
| [GitHub Copilot CLI](./cli/) | Conclua um fluxo de trabalho de ponta a ponta no terminal com o Copilot CLI |
| [GitHub Copilot no VS Code](./vscode/) | Use modos de agente, MCP e agentes personalizados no VS Code |
| [GitHub Copilot cloud agent](./cloud/) | Atribua trabalho pelo GitHub e revise as alterações assíncronas |

Cada workshop tem seus próprios pré-requisitos e exercícios. Comece pelo ambiente que corresponde à forma como você trabalha.
