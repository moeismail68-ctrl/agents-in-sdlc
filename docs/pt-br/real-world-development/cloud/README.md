O **[GitHub Copilot cloud agent](https://docs.github.com/copilot/concepts/agents/cloud-agent/about-cloud-agent)** permite que o GitHub Copilot trabalhe de forma assíncrona na nuvem. Você atribui trabalho no GitHub, e o agente de nuvem o executa em segundo plano — explorando o repositório, fazendo alterações e abrindo uma pull request — enquanto você fica livre para outras atividades.

Ao longo destas lições, você adicionará instruções personalizadas que o agente de nuvem seguirá e atribuirá uma issue do GitHub para que ela implemente o trabalho. Você revisará agentes personalizados para orientar a abordagem, acompanhará e direcionará sessões no painel de agentes e concluirá revisando pull requests e iterando sobre os resultados.

## Pré-requisitos

Antes de participar deste workshop, verifique se você tem:

- [ ] Uma conta do GitHub com um plano ativo **Copilot Student, Pro, Pro+, Business ou Enterprise**
- [ ] O agente de nuvem do Copilot habilitado para sua conta ou organização

> [!TIP]
> Não tem um plano pago? Estudantes verificados podem obter o GitHub Copilot gratuitamente por meio do [GitHub Education][callout-student-plan-education]. O plano **Copilot Student** inclui o agente, MCP, revisão de código e recursos do Copilot CLI usados neste workshop.

[callout-student-plan-education]: https://github.com/education/students

> [!NOTE]
> O agente de nuvem está disponível nos planos **Copilot Student, Pro, Pro+, Business e Enterprise** — todos, exceto o Copilot Free. No Copilot Business ou Enterprise, um administrador precisa habilitá-lo para sua organização.

> [!NOTE]
> MCP não é abordado neste workshop. Para explorar servidores MCP com o Copilot, consulte o [workshop da CLI](../cli/) ou o [workshop do VS Code](../vscode/).
