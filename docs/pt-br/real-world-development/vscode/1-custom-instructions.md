Neste exercício, você explorará como arquivos de instruções fornecem contexto a GitHub Copilot no VS Code.

1. Abra `.github/copilot-instructions.md`.
2. Revise as diretrizes gerais do projeto.
3. Abra os arquivos em `.github/instructions`.
4. Observe como o campo `applyTo` limita uma instrução a determinados tipos de arquivo.
5. Adicione um padrão específico do projeto que reflita os requisitos do Tailspin Toys.

> [!TIP]
> Mantenha instruções claras e verificáveis. Explique o resultado esperado e forneça exemplos quando necessário.
