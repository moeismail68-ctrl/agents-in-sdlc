Antes de iniciar os exercícios no VS Code, prepare o repositório Tailspin Toys em um GitHub Codespace ou em um dev container local.

1. Acesse o [modelo Tailspin Toys][tailspin-template].
2. Crie uma cópia do repositório com **Use this template**.
3. Abra o repositório em um Codespace ou em VS Code.
4. Confirme que GitHub Copilot está instalado e habilitado.
5. Use a [documentação do VS Code][vscode-docs] caso precise configurar o ambiente.

[tailspin-template]: https://github.com/github-samples/tailspin-toys
[vscode-docs]: https://code.visualstudio.com/docs
