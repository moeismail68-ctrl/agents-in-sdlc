Neste exercício, você configurará um servidor MCP e permitirá que o Copilot acesse uma ferramenta externa.

1. Revise as configurações MCP do projeto.
2. Configure o servidor necessário para o cenário.
3. Reinicie ou atualize a sessão do Copilot.
4. Confirme que a ferramenta MCP aparece como disponível.
5. Solicite ao agente que use a ferramenta para observar ou validar o aplicativo.

> [!CAUTION]
> Autorize somente os recursos necessários e revise qualquer ação externa proposta pelo agente.
