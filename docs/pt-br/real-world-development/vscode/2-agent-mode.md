Neste exercício, você usará o modo agente no VS Code para explorar o repositório e implementar uma alteração controlada.

1. Abra o Copilot Chat e selecione o modo agente.
2. Descreva a tarefa e os critérios de aceitação.
3. Permita que o agente inspecione o projeto e proponha uma abordagem.
4. Revise as ferramentas e alterações antes de autorizá-las.
5. Execute os testes relevantes e revise o diff.

> [!NOTE]
> O modo agente pode executar várias etapas, mas você continua responsável por aprovar ações importantes e revisar o resultado.
