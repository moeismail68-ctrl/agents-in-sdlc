Nesta lição, você conhecerá comandos de barra úteis do Copilot CLI.

## Comandos principais

Use `/new` para iniciar uma sessão limpa, `/diff` para revisar alterações e `/exit` para sair do programa.

Outros comandos permitem gerenciar contexto, selecionar modelos, compartilhar uma sessão ou delegar trabalho ao agente de nuvem. Consulte a ajuda integrada do Copilot CLI para ver os comandos disponíveis no ambiente atual.

> [!TIP]
> Use comandos de barra brevemente e deliberadamente. Sempre revise o estado da sessão antes de compartilhar ou delegar trabalho.
